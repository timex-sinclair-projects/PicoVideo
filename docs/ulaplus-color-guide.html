PicoVideo 4.6 · TS 2068

ULAplus Color Guide

How PicoVideo turns one byte into a color, what the numbers actually mean, and a builder that writes the BASIC to load your own 64-color palette.

1One byte is one color

Every color PicoVideo sends to the monitor is a single byte. The byte is split into three small numbers: how much green, how much red and how much blue. The monitor adds the three lights together, so the color you see is just those three amounts mixed.

Green and red get 3 bits each, so they go from 0 (off) to 7 (full). Blue gets only 2 bits, so it goes from 0 to 3. That's 8 × 8 × 4 = 256 possible colors. Move the sliders and watch the bits.

2Where 32, 4 and 1 come from

The formula you'll see everywhere, 32×G + 4×R + B, isn't a scaling rule. It's just where each number sits inside the byte:

Bit76543210
HoldsGGGRRRBB
Bit value1286432168421

Green's lowest bit is worth 32, so green level G adds G×32. Red's lowest bit is worth 4, so red adds R×4. Blue sits at the bottom and adds B. It's the same idea as writing a number in columns: the multiplier only says which column a digit goes in.

Going the other way, from a byte to its three levels:

G = INT (v/32)
R = INT (v/4) - 8*G      : REM same as INT(v/4) AND 7
B = v - 4*INT (v/4)      : REM same as v AND 3

Worked example: orange is full red, some green, no blue. Pick R=7, G=3, B=0: 3×32 + 7×4 + 0 = 96 + 28 = 124.

3What the levels mean

A level is a step of signal, not a percentage of anything. PicoVideo puts the bits straight onto the VGA wires through resistors, so level 7 is the strongest signal the board makes and each step below it is roughly one seventh less. Blue does the same thing in thirds. The firmware does no scaling of its own: the byte you write is the byte that reaches the connector.

If you're used to 0–255 color values from a PC, treat each step as an even share of 255:

The bars show how much light jon0x0 measured on one PicoVideo and one monitor (an ASUS VS238 in sRGB mode). The light isn't linear: level 4 of red gives only about 28% of full light, because monitors deliberately brighten in a curve. That curve is what makes evenly spaced signal steps look evenly spaced to the eye, so you can design with the plain 0–7 and 0–3 steps and ignore the light figures. They're here only to explain why the numbers don't look like halves and quarters.

Blue has half the stepsBlue's 4 levels sit at 0, 1/3, 2/3 and full, while red and green have 8. So most colors can't be balanced exactly. A true gray needs R and G equal and B at the nearest third: R=G=4 with B=2 is close, R=G=5 with B=2 is closer. Some ULAplus tools and emulators stretch blue to 8 steps for display. On PicoVideo blue really has 4.

5How attributes choose entries

With ULAplus off, an attribute's INK and PAPER numbers pick from the TS 2068's fixed 16 colors. With ULAplus on, they pick from a table of 64 entries that your program fills. The table is four groups of 16 called CLUTs. FLASH and BRIGHT choose the CLUT, so they stop flashing and brightening. Inside a CLUT, entries 0–7 are the eight INK colors and 8–15 the eight PAPER colors.

CLUTFLASHBRIGHTINK 0–7PAPER 0–7

The entry number is 16×(2×FLASH + BRIGHT) + INK for ink, and the same plus 8 for paper. The border always uses CLUT 0's paper entries: BORDER n shows entry 8+n.

6Talking to PicoVideo

PicoVideo uses the same two ports as a ULAplus Spectrum. Write a register number to port 48955 ($BF3B), then write or read its value at port 65339 ($FF3B).

RegisterWhat it holds
0–63The 64 palette entries, one color byte each. They can be read back.
64Palette switch: 0 is off, anything else is on.
 
OUT 48955,19: OUT 65339,124  : REM entry 19 = orange
OUT 48955,19: PRINT IN 65339 : REM read it back
OUT 48955,64: OUT 65339,1    : REM palette on
OUT 48955,64: OUT 65339,0    : REM palette off
Load the palette firstAll 64 entries are 0 (black) when PicoVideo starts. If you switch the palette on before loading it, the whole screen goes black, which looks like a crash but isn't.

8Mixing recipes

  
Hue comes from the ratio between the channels; brightness comes from how high they are. To darken a color, lower every channel by about the same proportion. To make it paler, raise the channels that are low. Click a row to load it.

Ramps

  
A smooth ramp from dark to light keeps the ratio and steps all channels up together. Red and green have 8 steps, so a ramp of one hue can have 8 shades at most, and fewer if blue is involved, since blue changes only every two or three steps.
